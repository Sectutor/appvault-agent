# 🚀 Install AppVault — one click

Welcome! You're one click away from your own AppVault server.

## What happens next
Click the **Run** button below (or run this in the terminal):

```bash
bash deploy/deploy-gcp.sh
```

The script will:
1. ✅ Open the store port in your cloud firewall (automatic)
2. ✅ Create your AppVault server (a small Debian VM)
3. ✅ Install AppVault on it automatically (~4 minutes)
4. ✅ Print your Store URL — that's it

## After the install
1. Open the **Store URL** it prints (e.g. `http://12.34.56.78:8085`)
2. Install any of the **10 free apps** (n8n, WordPress, Vaultwarden, Jellyfin…)
3. When you launch your first app, AppVault shows you how to make your server **invisible to the internet** (30 seconds, Tailscale)
4. Premium apps unlock with a license key you get after paying

**No terminal skills needed. No manual steps. Just click Run.**
